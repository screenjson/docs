screenjson-server is a platform for editing and managing screenplays as data, at scale. It keeps a library of scripts as ScreenJSON in a database you run, puts a **REST API** and an **MCP server** in front of it, and lets any number of people, programs and AI agents work on the same scripts at once without overwriting each other.

## What it is for

- **Collaborative agent editing.** `/mcp` gives Claude, Cursor and other MCP clients the library as tools: read outlines and scenes, search, edit, insert and move lines. Several agents can work on the same scripts at once, each under its own token, and every change is validated and conflict-checked like a human editor's. See [MCP](/tools/server/mcp).
- **An API for every line.** Every scene, line, character, note and translation has its own URL. Read it, patch it, move it. Around 130 routes, described in the built-in explorer at `/swagger/`. See [How the API works](/tools/server/api).
- **Mass editing.** A *pass* hands a library-wide job ("translate every line of dialogue", "tag every scene's props") out to many workers or agents in batches, each line done once, with live progress.
- **Your NoSQL database.** Scripts live as JSON records in MongoDB, Elasticsearch, PostgreSQL (JSONB and pgvector), Chroma, Weaviate or Pinecone, split per script, per scene or per line, ready for your own queries.
- **S3 alongside.** Each script can be mirrored as a ScreenJSON file to S3, MinIO or Azure every time it goes quiet; exports and imports go through the same buckets. See [Script settings](/tools/server/settings).
- **Live.** Every change is an event on a websocket channel, per script, per library and per pass. The built-in web app re-renders scripts as agents edit them.
- **In and out.** ScreenJSON, Final Draft, Fade In, Fountain and PDF in; ScreenJSON, PDF and writer formats out, through [Greenlight](/tools/greenlight/overview); a Git repository per script; webhooks. See [Import and export](/tools/server/import-export).

## At a glance

| | |
|---|---|
| Runs as | One container, one port (8080) |
| REST API | `/documents`, `/imports`, `/jobs`, `/search`, `/tokens`, `/passes`, `/status`, `/config` |
| MCP | `/mcp` (streamable HTTP) |
| API explorer | `/swagger/`, and `/openapi.json` |
| Live events | A websocket at `/connection/websocket` |
| Databases | MongoDB, Elasticsearch, PostgreSQL (pgvector), Chroma, Weaviate, Pinecone, or memory |
| Object storage | S3, MinIO, Azure Blob Storage, or local disk |
| Web app | `/`: the library, imports, each script at `/#/d/{id}`, and the server's status and settings |
| Desktop | A Tauri app for Windows, macOS and Linux that opens any server |
